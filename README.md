# ksBatcher

Asynchronous request batching with flexible execution strategies, deduplication, caching and retries.
<br>Compatible with JDK 17 and later.

For documentation and usage examples, click [here](https://github.com/Xkyrell/ksBatcher/wiki).

#### Reliability
The library includes JUnit 5 tests covering core functionality.
